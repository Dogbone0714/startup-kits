# Startup Kits - 新創公司資源站

一個現代化的 React 網站，為新創公司提供完整的工具和資源集合。

## 功能特色

- 🎨 現代化的 UI/UX 設計
- 📱 響應式設計，支援各種裝置
- 🚀 使用 Vite 快速開發
- 🎯 分類清晰的資源展示
- ⚡ 流暢的動畫效果

## 技術棧

- React 18
- Vite
- CSS3 (現代化樣式)

## 開始使用

### 安裝依賴

```bash
npm install
```

### 開發模式

```bash
npm run dev
```

開發伺服器將在 `http://localhost:5173` 啟動

### 建置生產版本

```bash
npm run build
```

### 預覽生產版本

```bash
npm run preview
```

## 專案結構

```
startup-kits/
├── src/
│   ├── components/      # React 元件

│   │   ├── Resources.jsx
│   │   ├── ResourceCard.jsx
│   │   └── Footer.jsx
│   ├── data/           # 資料檔案
│   │   └── resources.js
│   ├── App.jsx         # 主應用元件
│   ├── main.jsx        # 應用入口
│   └── index.css       # 全域樣式

├── package.json
└── vite.config.js
```
